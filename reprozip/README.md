# ReproZip on x86 Linux

The course ReproZip tracing workflow requires x86 Linux. Tracing failed with Mac M-series Docker during course testing. See [platform support](../course-materials/README.md#platform-support).

See the [Docker setup instructions](docker-x86-linux/README.md). Student-facing instructions are in the [ReproZip lecture notes](../course-materials/REPROZIP_LECTURE_NOTES.md) and [worked tutorial](../course-materials/REPROZIP_TUTORIAL.md).

Start with the [Python sales example](../example/reprozip_sales/README.md) for a small demo with no compiler or license requirement.
